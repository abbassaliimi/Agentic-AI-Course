1-Day Hands-On Intensive Workshop

Agentic Engineering:
Building Stateful LLM Workflows

Move beyond basic single-prompt chatbots. Architect production-grade AI agents with persistent memory, asynchronous chat delivery, and autonomous tool execution.

Instructor: Ts. Dr. Abbas Saliimi Lokman
Format: Code-First Engineering Lab
Core Stack: Python 3.10+ LangGraph PostgreSQL Docker Telegram Bot API Llama-3 (Groq)

Course Goal: Master the transition from stateless LLM wrappers to cyclic, self-correcting ReAct agents capable of multi-turn memory and real-world database analytics.

Workshop Curriculum
MODULE 00 & 01

Isolated Infrastructure & DB

Configure isolated Python environments and deploy containerized PostgreSQL via Docker to power durable agent state persistence.

MODULE 02

Agentic Theory & ReAct Graphs

Design cyclic state machines in LangGraph using nodes, conditional edges, state reducers, and PostgreSQL checkpointing.

MODULE 03

Async Telegram Integration

Connect your agent to mobile & desktop via async long-polling, isolating multi-user memory threads by Telegram User ID.

CAPSTONE PROJECT

Autonomous Text-to-SQL Agent

Build a live Exploratory Data Analysis (EDA) bot that writes SQL, queries Postgres, and self-corrects syntax errors autonomously.
